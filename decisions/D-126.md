# D-126 · Контур без Docker: Vercel · Render · Supabase · GitHub Free

**Дата:** 2026-11-15 · **Статус:** принято · **Фаза:** F1
**Затронутые зоны:** `docs/`, `.github/workflows/ci.yml`, `.env.example`, `README.md`, `ARCHITECTURE.md`, `TZ.md`, `scripts/go-live-check.mjs`, `AGENTS.md`, `decisions/`

## Контекст

После D-125 разработка переехала на локальный ПК Win10 x64 / i3-7100U / 6 ГБ RAM.
Мастер явно сообщил, что **Docker использоваться не будет** — он тяжелее самой
разработки. В качестве альтернативы задан бесплатный стек: **Vercel · Render ·
Supabase · GitHub Free**. Дополнительно: в ознакомительном `synapse` был Godot,
но Vault — не игра на движке, хотя игровые элементы в продукте есть. Также Мастер
подтвердил постоянное правило: **каждое обновление репозитория завершается PR и
мержем**, а не оставляет коммит на ветке без PR.

Ранее `docs/costs.md` рекомендовал российский платный хостинг (Amvera/Beget) из-за
152-ФЗ и сложностей с РФ-картами; `README.md` и `ARCHITECTURE.md` начинались с
`docker compose up --build`; CI содержал job `docker` со сборкой четырёх образов.

## Решение

1. **Docker исключён из активного контура.** `docker-compose.yml`, Dockerfile'ы и
   `frontend/nginx.conf` сохраняются как архивная справка, но не требуются
   локально, не собираются в CI и не рекомендуются в документации. Удаление —
   отдельным ADR, если self-host окончательно не вернётся.
2. **Разделение сервисов:** GitHub (код, PR, Secrets, Actions, артефакты) →
   Vercel (статика `frontend/` и preview) → Render (долгоживущий backend +
   Telegram-бот: Express + socket.io + cron) → Supabase (managed PostgreSQL,
   `DATABASE_URL`) → GitHub Actions (типы, `pg-mem`, `postgres:16`, сборка,
   кадры, локальный контур). OpenRouter остаётся только на ПК Мастера.
3. **Supabase — удалённый Free-проект.** CLI допустим для `link` / `db push` /
   миграций, но `supabase start` не применяется: он требует Docker. Локально схему
   проверяет CI job `schema`, при желании — `psql` против удалённой БД.
4. **Redis не обязателен.** В коде есть fallback на in-process/БД-гварды; на
   free-тарифе `REDIS_URL` оставляем пустым. Распределённые локи и socket.io
   adapter — отдельное решение Ф2.
5. **Godot не переносится.** Vault = Telegram Mini App на React + Vite + three.js;
   механики серверные, 3D — браузерные сцены и `.glb` из Blender. Новый движок
   возможен только новым ADR под нативный клиент/отдельную игру.
6. **Инструменты «на всякий случай»** вынесены в `docs/TOOLBOX.md`: `gh`, Vercel
   CLI, Supabase CLI, Render CLI, `psql`, `jq`, `rg`, `@gltf-transform/cli`,
   Playwright, ffmpeg, Volta. Ничего из списка сейчас не ставится; всё ставится
   одной командой без Docker.
7. **Правило PR + мерж** зафиксировано в `AGENTS.md` и `docs/STATUS.md`: любая
   правка → коммит на активную ветку → PR → зелёные проверки → `gh pr merge`.
8. **152-ФЗ не отменяется, а откладывается.** Бесплатные зарубежные тарифы —
   активный выбор для разработки и testnet; вопрос локализации данных для
   РФ-аудитории остаётся открытым перед реальными игроками. Amvera/Beget —
   fallback, прежняя смета сохранена в `docs/costs.md` как архивная справка.

## Отклонено

- **Оставить `docker` job в CI «на будущее».** Раз в Docker не работаем, сборка
  образов перестала быть доказательством и только тратит минуты Free-раннера.
- **Поднимать Supabase локально через CLI.** Это тот же Docker, просто спрятанный.
- **Сразу закоммитить `render.yaml` / `vercel.json`.** Инфраструктура включается
  миссией Ф2; шаблон лежит в `docs/DEPLOY-FREE.md` текстом.
- **Тащить Godot «потому что в synapse был».** Разные продукты, разные пайплайны
  ассетов; лишний движок на 6 ГБ RAM не оправдан.
- **Молча выбросить анализ 152-ФЗ.** Решение Мастера меняет активный контур, но не
  снимает юридический риск; документ помечен как архивная справка.

## Проверка

- `npm run test:local` — 32/32, включая пробу «в CI нет `docker build`, ADR и
  `docs/DEPLOY-FREE.md` фиксируют четыре сервиса, `TOOLBOX.md` предупреждает про
  `supabase start`».
- `npm run verify`, `npm run board`, `npm run board:check`, `npm run context:check`.
- `npm run go-live:check` по-прежнему честно красный в демо-режиме, но теперь
  требует `docs/DEPLOY-FREE.md` вместо `docker-compose.yml` и отклоняет
  `DATABASE_URL` с `localhost`.
- CI: `backend`, `schema`, `frontend`, `bot`, `local-tools`; job `docker` удалён.
- Изменения проходят через PR и мерж (правило Мастера).
