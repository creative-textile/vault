# Решения (ADR)

Одно решение — один файл `D-<номер>.md`. Нумерация продолжает журнал старого
контура; сам 550-КБ журнал Arena-эпохи удалён вместе с транспортом (D-125),
сохранён только компактный указатель [`LEGACY.md`](LEGACY.md).

Формат шапки обязателен и читается оркестратором/доской:

```md
# D-<номер> · <название>

**Дата:** ГГГГ-ММ-ДД · **Статус:** предложено | принято | отклонено · **Фаза:** F<N>
**Затронутые зоны:** <пути>
```

Дальше: `## Контекст`, `## Решение`, `## Отклонено`, `## Проверка`.
Изменение контракта, оракула, лимита бюджета или границ продукта без ADR не
принимается. `context-pack.mjs` подключает в промпт только ADR, явно
перечисленные в `decisions[]` карточки, и режет файл по 8000 символов: большие
полотна в платный контекст не попадают.

Активные решения нового контура: [`D-125.md`](D-125.md) (миграция на локальный
Git/API) и [`D-126.md`](D-126.md) (отказ от Docker, Vercel/Render/Supabase/GitHub
Free, правило PR + мерж). [`LEGACY.md`](LEGACY.md) — только указатель старых
продуктовых решений, чей 550-КБ журнал удалён.
