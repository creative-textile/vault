# D-125 · Локальная разработка через API вместо транспорта Arena

**Дата:** 2026-11-15 · **Статус:** принято Мастером · **Фаза:** F1
**Затронутые зоны:** `tools/local/**`, `tasks/**`, `decisions/**`, `verdicts/**`, `costs/**`, `.github/workflows/ci.yml`, `package.json`

## Контекст

Разработка переносится с Arena на локальный ПК (Win10 x64, i3-7100U, 6 ГБ RAM).
ИИ перестал быть условно бесплатным: оплата через OpenRouter, лимит `$15` на
фазу, план `$13.46` (27 задач + 22 решения + 5 приёмок). Старый контур держался
на браузерном userscript ScriptCat 1.16.1, четырёх базах Notion, Google Drive
Gateway и DOM-автоматизации чата Arena; в `vault` он так и не был запущен в бою
(`Agent URL` ролей пусты), а его стоимость в репозитории — 219 файлов / 5,31 МБ
и 550 КБ журнала решений, которые нельзя кормить в платный промпт.

## Решение

1. **Транспорт удаляется, а не архивируется.** История ScriptCat, Notion, Drive,
   telemetry, `_push/*.patch`, X11-стабы `bpy`, авто-коммит кадров CI — всё, что
   существовало только для песочницы, уходит из репозитория. Мастер отдельно
   подтвердил: историю транспорта не сохраняем.
2. **Носитель процесса — один репозиторий Git.** `tasks/` (карточки и миссии),
   `decisions/` (ADR), `verdicts/` (вердикты с evidence), `costs/ledger.jsonl`
   (факт расходов), `docs/board/index.html` (доска, генерируется из тех же
   файлов). Notion и Google Drive не участвуют; публичные ссылки доступны, но
   данные в новую систему не переносятся.
3. **Учёт денег — первый и обязательный шаг.** `tools/local/budget.mjs` пишет
   `usage.cost` каждого ответа OpenRouter, считает `$/роль`, `$/модель`,
   `cached_share` и запрещает выдачу (`exit 2`) при выходе за лимит фазы.
   Второй независимый контур — Workspace Budgets в кабинете OpenRouter.
4. **Диета контекста.** Неизменный system-prefix `docs/PROCESS.md` + `session_id`
   для кэша провайдера; `context-pack.mjs` собирает ≤12 000 токенов только из
   scope-файлов и нарезок ADR; большие документы целиком в промпт не попадают.
   Превышение — ошибка с разбивкой по секциям, не тихая обрезка.
5. **Оркестратор без зависимостей.** `tools/local/run.mjs`: бесплатные гейты →
   `budget check --add` → один вызов → JSON по схеме → вердикт → журнал → статус
   в Git. Батч (−50 %) для аудита/приёмки/планов, синхронно — исполнитель.
   Маркеры `CF_*`, напоминания, `tool-call limit`-продолжения и provisioning
   заменены структурированным выводом и обычным retry с тем же `call_id`.
6. **Два независимых замера — локальные скрипты, а не второй платный вызов.**
   Разные инструменты, разные `result_sha`; повтор модели за полную цену
   независимости не даёт. Если второе мнение модели всё же нужно — обе отправки
   уходят в батч.
7. **Blender — нативный, зафиксированный.** `5.3.0` portable, `--background
   --factory-startup --gpu-backend opengl -t 2`, CPU-рендер 640px, версия
   сверяется с `tools/modeling/blender-version.json`. Запасной путь — `5.2.4 LTS`.
   pip-`bpy`, стабы X11 и `env_setup.sh` удалены. `.blend` 4.5.3 не
   пересохраняются до зелёных гейтов `audit_glb.py` + `validate_glb.mjs` +
   сверки якорей.
8. **Оракул не ослаблен.** Проверки зашиты в `tools/local/preflight.mjs`
   списком в коде (наследие `relay-build.mjs`), а не читаются из `package.json`.
   `npm run verify` — быстрый локальный контур, `npm run preflight:full` — полный
   прогон продукта после `npm ci`. Пропуск из-за отсутствующих зависимостей
   печатается как `SKIP` и не считается pass.

## Сохранённые инварианты старой системы

| Было | Стало |
|---|---|
| Фаза → миссия → карточка, ТЗ и оракул обязательны | `tasks/**/*.json`, `docs/PROCESS.md` §2 |
| Зоны записи, гейты, «оракул не ослабляется» | `zone[]`, `run.mjs`, `preflight.mjs` |
| `dispatch_id` / `run_id`, идемпотентность хода | `call_id = <карточка>/<роль>/<попытка>` в ledger |
| Статусы `Ready/Running/Submitted/Accepted/Rework` | те же статусы в `tasks/`; добавлен `blocked` и `defect_owner` |
| Доказательство = команда + rc + SHA | `commands[]`, `evidence[]`, два независимых инструмента |
| ADR, пауза при неясности, запрет тихого дефолта | `decisions/D-*.md`, `status: need_master` |
| Проверки узлом, а не манифестом | `preflight.mjs`; `SKIP` и `KNOWN` не считаются pass, `--full` оставляет красный гейт красным |

## Отклонено

- **Архивировать транспорт «для понимания».** Мастер решил удалить: понимание
  обеспечено этой таблицей и компактным `decisions/LEGACY.md`, а не 5 МБ кода.
- **Обновить Blender первым делом.** Релиз 5.3 от 10.11.2026 меняет glTF-экспорт
  (KTX2, animation pointers) и требует Python 3.13; официальный минимум — 8 ГБ
  RAM и Vulkan 1.3 при 6 ГБ на машине. Обновление идёт после гейтов, с пином.
- **Считать деньги по оценкам стека v3.** Факт только из `usage.cost`; оценки
  нужны лишь для `check --add`.

## Проверка

`npm run verify` (пробы локального контура, доска, контекст-паки, бюджет,
`git diff --check`), `npm run card:plan -- --card tasks/F1/LOCAL-0-K1.json`
(сухой прогон без сети и ключа), `npm run board`, `npm run blender:check` на
локальной машине. CI: `local-tools` + продуктовые джобы без `scriptcat`.
