# 👁 Как проверяется визуал сцен

**Решение:** D-120 (идея) + D-125 (перенос на локальную машину).
**Инструмент:** `frontend/tests/eyes/frames.mjs`.

Числа (`tests/scene-math.mjs`, `shader-lint.mjs`) проверяют математику, но не
видят чёрный кадр, уехавшую камеру, лопнувший материал и пустую сцену.
Поэтому нужен настоящий браузер и PNG.

## Локально (основной путь)

```powershell
cd frontend
npm i -D playwright           # один раз
npx playwright install chromium
npm run eyes -- --frames 12 --span 6000
start frames\frame-000.png
```

Скрипт сам поднимает **dev-сервер Vite** и снимает `/scenes.html` — отладочную
галерею, которой не нужны backend, база и авторизация. WebGL без GPU:
`--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`.

Если Playwright/Chromium нет, скрипт **падает с rc=1** и называет команду
установки. Раньше он «мягко выходил с кодом 0, потому что песочнице Arena не
хватало браузера»; это был пропуск, замаскированный под успех, и он удалён.

## В CI

Job `frontend` ставит Chromium, снимает 12 кадров и кладёт их артефактом
`scene-frames`. **Коммит кадров в ветку убран**: на локальной машине файлы уже
рядом, а авто-коммит от имени `vault-eyes` создавал шум в истории и гонки с
рабочим деревом.

## Две ловушки, найденные практикой

1. **`vite preview` не годится.** `scenes.html` намеренно не входит в прод-сборку;
   `preview` отдаёт `index.html` с кодом 200, и в кадр попадал онбординг вместо
   3D. Сервер проверяется по содержимому (`scenes.tsx`), а не по коду ответа.
2. **Кадр 0 в CI может быть пустым:** SwiftShader считает на CPU, первый кадр
   появляется через ~1.5–2 с. В сцене оставлен двухсекундный прогрев
   (`firstFrameAt + 2000`), решения о качестве принимаются после него.

## Границы

- Это кадры, а не видео: движение оценивается по последовательности.
- **FPS 6–9 в CI — не показатель:** SwiftShader считает на CPU. Гейт 30 FPS
  проверяется только на реальном устройстве.
- Звук так не проверить — `tools/audio/audit_audio.py`.
- «Как ощущается на телефоне» не автоматизируется: финальная визуальная
  приёмка остаётся за Мастером.
