# Сколько стоит запустить Vault: кошелёк и хостинг

Версия 1.0 · 2026-11-12 · фаза 1 · ответ на вопросы Мастера
Цены сверены по открытым источникам в ноябре 2026. Курс: €1 ≈ $1.08.
**Это не счёт, а карта вариантов.** Решение — за Мастером, документ фиксирует развилку.

## 1. Короткий ответ

| Вопрос | Ответ |
|---|---|
| Сколько стоит аппаратный кошелёк | **€59–69** (~$64–75) за Ledger Nano S Plus — цена устройства, без подписки |
| Обязателен ли он сейчас | **Нет.** Фаза 2 идёт на testnet с ручной подписью — бесплатно |

**Главный вывод:** на текущей стадии покупать ничего не нужно. Покупка кошелька имеет смысл не
раньше, чем за месяц до первых реальных выплат, и это €69, а не «инфраструктура за $50/мес».

## 2. Аппаратный кошелёк

### 2.1 Главное ограничение: TON

Наш контракт — **TON → BEP-20 → ERC-20**. Это отсекает половину рынка:

| Устройство | TON | BEP-20 | ERC-20 | Вывод |
|---|---|---|---|---|
| **Ledger** (Nano S Plus, Nano X, Flex, Stax) | **да**, официальное приложение | да | да | подходит |
| **Trezor** (Safe 3, Safe 5, Model One) | **нет** (по состоянию на октябрь 2026) | да | да | **не подходит** |
| SafePal, Ellipal и подобные | ограниченно | да | да | проверять отдельно |

Trezor дешевле и с открытой прошивкой, но **TON он не умеет** — для нас это дисквалификация,
пока мы держим TON первым в порядке сетей (Ф0-4). Это не мнение, это проверяемый факт из
документации обоих производителей.

Старый Ledger Nano S (без Plus) тоже не подходит: памяти не хватает на приложение TON.

### 2.3 Где покупать (и где не покупать)

| Где | Можно? | Почему |

Доставка в Польшу с shop.ledger.com — обычная, плюс VAT (в цене для ЕС обычно уже включён).
**Заказывать только с официального сайта**, даже если на маркетплейсе на 100 злотых дешевле:
экономия 100 злотых не стоит риска потерять кассу проекта.

Правило на будущее, которое стоит запомнить один раз: **seed-фраза генерируется только на самом
устройстве**, никогда не вводится на компьютере и никогда не фотографируется. Любой сайт или
«поддержка», которые просят фразу, — мошенники.

### 2.4 Бесплатные варианты: да, они есть

| Вариант | Стоимость | Что даёт | Чем платим |
|---|---|---|---|
| **Testnet + ручная подпись** (текущее решение, D-…) | **$0** | вся логика выплат отлаживается без реальных денег | ничего, кроме времени |
| **Бесплатный мобильный кошелёк** (Keeper/Tonkeeper, Trust, MetaMask) | **$0** | ключ живёт в телефоне, подпись — пальцем | ключ на устройстве с интернетом |
| **Бесплатный кошелёк + лимиты на сервере** | **$0** | выплаты до $X уходят автоматически, выше — вручную | нужны лимиты и сверка (уже в правилах) |
| Аппаратный кошелёк | €59 один раз | ключ физически не покидает устройство | разовая покупка + неудобство |
| Кастодиальный сервис (Fireblocks, BitGo) | $300–3000+/мес | страховка, AML, аудит | **дороже всего, нам не нужно сейчас** |

**Сервисов «подпись за небольшую комиссию» для нашего случая не бывает.** Комиссия (% от
оборота) — это модель платёжных шлюзов и кастодианов, и она имеет смысл при тысячах выплат.
На 5–50 выплатах в день кастодиан стоит дороже, чем весь остальной проект.

## 3. Хостинг API за $0

### 3.1 Почему не Vercel

Наш `backend/` — это **Express + socket.io + Redis + крон**. Vercel запускает только
serverless-функции: процесс живёт секунды, WebSocket-соединение и `node-cron` там не работают.
Поэтому фронтенд — на Vercel (уже работает), а API нужен отдельный хост с постоянным процессом.

### 3.2 Варианты, проверенные в ноябре 2026

| Хостинг | Бесплатно | Засыпает? | Карта? | Годится нам |
|---|---|---|---|---|
| **Render** | 750 часов/мес, 512 МБ, 0.1 CPU | **да, через 15 мин** тишины, подъём ~30–60 с | **нет** | **да — основной вариант** |
| **Cloudflare Workers** | 100 000 запросов/день | нет (но это не процесс) | нет | **нет**: нет WebSocket-сервера и cron |
| **Oracle Cloud Always Free** | 2 OCPU / 12 ГБ ARM, 200 ГБ диска | **нет** | **да** (для верификации) | **да — если нужен «никогда не спит»** |
| **Supabase** (база) | 500 МБ базы, 5 ГБ трафика | проект **пауза через 7 дней** тишины | нет | **да — база** |
| **Upstash** (Redis) | 10 000 команд/день, 256 МБ | нет | нет | **да, но лимит жёсткий** |
| Railway | $1 кредита в месяц после триала | по кредиту | нет | нет — на сутки-двое |
| Fly.io | бесплатного тарифа нет с 2024 | — | да | нет |
| Koyeb | закрыт для новых аккаунтов (февраль 2026) | — | — | нет |

### 3.3 Что реально выбрать

**Вариант 1 — «сон разрешён» (рекомендую): Render free.**
```
Render: Express-сервер, 750 ч/мес ($0)
Supabase: PostgreSQL ($0)
Upstash: Redis, если он нужен ($0)
Vercel: фронтенд ($0)
```
Плюс: без карты, за 20 минут. Минус: первый игрок после паузы ждёт ~минуту. Для теста и первых
игроков это нормально — и ровно то, что Мастер уже одобрил («засыпание допустимо», Ф0-5).

**Вариант 2 — «никогда не спит»: Oracle Cloud Always Free.**
Настоящая бесплатная VM (2 ядра, 12 ГБ) — Express + socket.io + Postgres в Docker живут
круглосуточно. Это **единственный способ получить постоянный процесс за $0**. Минусы: нужна
карта для верификации (не списывается), бывает ошибка «out of host capacity» в вашем регионе,
и это полноценный сервер, который надо обновлять. Для нас — вариант «когда появится 100+
игроков одновременно».

**Вариант 3 — «$5 и не думать».** Railway Hobby или Render Starter ($7): постоянный процесс без
прыжков. Дороже нуля, но дешевле любых нервов. Мастер просил $0 — поэтому это план Б, а не план А.

### 3.4 Честные ограничения бесплатного

1. **Первый игрок ждёт.** Render поднимается ~минуту. Для Mini App это выглядит как «долго
   грузится», поэтому экран «Сервер просыпается, подождите» — не костыль, а обязательная часть UI.
2. **Supabase засыпает через 7 дней.** Если проект неделю никто не трогал — база на паузе.
   Поднимается кнопкой в панели за пару минут, данные не теряются.
3. **Upstash — 10 000 команд в день.** На игру с матчами этого может не хватить: Redis считает
   каждую операцию. Либо лимиты, либо в фазе 2 свой Redis на том же Oracle-сервере.
4. **Render не для продакшена по своим же правилам.** Он честно пишет: «не используйте бесплатные
   инстансы для продакшена». Это значит: тест — да, реальные деньги игроков — потом на платное.
5. **Бесплатное не бывает вечным.** За 2026 год закрылись Fly.io free, Koyeb free, урезали
   Oracle и Render. Поэтому конфигурация — в переменных окружения, чтобы переезд был сменой
   адреса, а не переписыванием кода.
