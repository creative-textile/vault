# Локальная разработка через API · архитектура контура (v2)

**Дата:** 2026-11-15 · **Решение:** [`D-125`](../decisions/D-125.md) · **Статус:** реализовано.
Практический старт — [`LOCAL-DEV.md`](LOCAL-DEV.md), правила для модели —
[`PROCESS.md`](PROCESS.md), короткий вход агента — [`../AGENTS.md`](../AGENTS.md).

## 1. Что изменилось

| Было (Arena) | Стало (локальный ПК) |
|---|---|
| ScriptCat 1.16.1: userscript в браузере, DOM-ввод, маркеры `CF_*` | `tools/local/run.mjs`: HTTP к OpenRouter, JSON по схеме |
| 4 базы Notion, Google Drive Gateway (logs/payloads/artifacts), ntfy | `tasks/`, `decisions/`, `verdicts/`, `costs/ledger.jsonl` — всё в Git |
| Бесплатный ИИ, суточная квота `Daily usage limit` | `$15` на фазу, `usage.cost` в журнале, два контура защиты |
| Лимит промпта 7500 **знаков**, payload-канал через Drive | лимит 12 000 **токенов**, контекст-пак из scope-файлов, кэш system-prefix |
| `bpy` из PyPI + X11-стабы, кадры коммитятся в ветку | нативный Blender 5.3 portable, кадры локально/артефактом CI |
| 219 файлов / 5,31 МБ транспорта + 550 КБ журнала решений | удалено; переносимые инварианты — таблица в D-125 |

Транспорт в `vault` не был запущен в бою (`Agent URL` пусты), поэтому живое
состояние переносить не пришлось. Боевой опыт из `synapse` учтён: цикл вставал
на стыках (противоречивое ТЗ, нет причины возврата, промпт 8178 > 7500,
маркер без перевода строки) — теперь стыки это machine-readable файлы и
проверки **до** платного вызова.

## 2. Схема

```
tasks/F1/*.json ──► run.mjs ──► [бесплатные gates] ──► budget check --add
                       │                                   │
                       ├─ context-pack.mjs (≤12k токенов)  │ exit 2 = стоп
                       │     system = PROCESS.md (кэш)      │
                       │     user   = scope + ADR           │
                       ▼                                   ▼
              OpenRouter /chat/completions  или  /batches
                       │  usage.cost, cached_tokens
                       ▼
     costs/ledger.jsonl ◄── budget.mjs      verdicts/*.json ──► tasks (статус)
                       └──────────────► board.mjs ──► docs/board/index.html
```

Один процесс, один лок-файл (нет «одна активная вкладка на проект»). Сеть нужна
только на шаге вызова; `card:plan` работает офлайн и ничего не списывает.

## 3. Экономика и оптимизация токенов

Смета стека v3: 27 задач × `$0.38` = **`$10.26` (76 % фазы)**, планы `$0.29`,
аудит пачкой `$1.58`, приёмка пачкой `$0.53`, комиссия пополнения ~`$0.70`
→ ≈ `$13.46` при лимите `$15`. Отсюда приоритеты:

1. **Не платить за переделки** (+10–15 % = `$1.3–2.0` за фазу): бесплатные
   локальные гейты до аудитора и приёмщика, структурированный вывод, явная
   причина возврата с `defect_owner`.
2. **Контекст-пак ≤12 000 токенов.** Большие документы — бывший
   `docs/DECISIONS.md` (550 КБ, удалён D-125), `ARCHITECTURE.md` (168 КБ)
   и `README.md` (62 КБ) — в промпт не попадают.
   Срез ADR — по `decisions[]` карточки, с жёстким cap 8000 символов.
3. **Кэшируемый префикс.** `PROCESS.md` байт-в-байт одинаков для всех карточек,
   `session_id = <фаза>/<карточка>` удерживает sticky routing; KPI —
   `cached_tokens / prompt_tokens` в `budget:report`.
   [Prompt Caching](https://openrouter.ai/docs/guides/best-practices/prompt-caching).
4. **Батч −50 %** для Coordinator/Auditor/Acceptor. Одна модель и один endpoint
   на батч, результаты по `custom_id`, `usage.cost` — факт списания
   [Batch API](https://openrouter.ai/docs/guides/features/batch-api). Важно: батч
   **не группируется по `session_id`**, поэтому кэш и −50 % не складываются —
   выбор делается по данным журнала.
5. **Маршрутизация по путям диффа:** Argon — только деньги/ключи/миграции,
   ≤4 за фазу; Flash — карточки со скриптовым оракулом (каждая −$0.24);
   изображения — сначала локальный Blender ($0), генерация по остаточному
   принципу.
6. **Два независимых замера = два локальных инструмента**, а не второй платный
   вызов. Проверяется кодом: разные `tool`, разные `result_sha`.
7. **Учёт без доп. запросов:** каждый ответ несёт `usage.cost`, токены и кэш
   [Usage Accounting](https://openrouter.ai/docs/cookbook/administration/usage-accounting).
   Второй контур — [Workspace Budgets](https://openrouter.ai/docs/guides/features/workspaces/workspace-budgets)
   (`403` при превышении daily/weekly/monthly).

## 4. Инварианты, пережившие смену транспорта

Оракул не ослабляется; зона записи — граница PR; `call_id` идемпотентен;
доказательство = команда + rc + SHA; ADR на изменение контракта/лимита;
неясность → `need_master`, а не тихий дефолт; проверки зашиты в
`tools/local/preflight.mjs` кодом, а не читаются из `package.json`; пропуск
проверки печатается `SKIP` и не считается pass. Известный красный гейт
продукта печатается `KNOWN` и в быстром `verify` не маскируется под успех —
в `--full` он остаётся настоящим `FAIL`. Полная таблица — D-125 §
«Сохранённые инварианты».

## 5. Решения, принятые по усмотрению исполнителя

| Вопрос | Решение | Почему |
|---|---|---|
| История транспорта | **Удалена** (подтверждено Мастером) | 5,31 МБ кода и 550 КБ решений — токенная бомба; понимание сохранено таблицей инвариантов и `LEGACY.md` |
| Blender | **5.3.0 portable, запинен**, запасной 5.2.4 LTS | 5.3 вышел 10.11.2026, меняет glTF-экспорт и требует Python 3.13; на 6 ГБ RAM и Vulkan 1.3 нужен `--gpu-backend opengl` |
| Оркестратор | **Самописный Node без зависимостей** | всё в Git, аудируемо, работает офлайн в `card:plan`, не тащит фреймворк в 6 ГБ RAM |
| Журнал расходов | **Коммитится в Git** (`costs/ledger.jsonl`) | отчётность фазы и `$/карточка` должны быть проверяемы историей; секретов в журнале нет |

## 6. Границы

- Секреты не в Git. Большие бинарные ассеты уже в репозитории (~31 МБ); Git LFS
  — только если вес вырастет, не сейчас.
- Визуальная приёмка и «как ощущается на телефоне» остаются за Мастером:
  ни числа, ни модель не заменяют глаза.
- `card:run` не делает коммит и не пушит: изменения и вердикт появляются в
  рабочем дереве, решение о коммите — у Мастера/роли.
- Батч даёт задержку до 24 ч (обычно минуты): интерактивный исполнитель идёт
  синхронно, не ждущие ответа роли — батчем.
