# Два языка: русский и английский

Версия 1.2 · 2026-11-12 · решения Мастера · статус: **принято** (D-112, D-114, D-116).
Дополняет `docs/art-direction.md` (визуал) и `docs/REGULATION.md` §10 (язык и локали).

## 1. Что решено

Vault выходит **на двух языках — русский и английский**. Это не «потом», а требование к
продукту: агент, который пишет пользовательский текст, обязан писать его так, чтобы второй язык
появился без переписывания экранов.

Три вопроса, которые решались Мастером, **закрыты** (D-114, 2026-11-12):

| Вопрос | Решение | Как ведём себя |
|---|---|---|
| Язык по умолчанию | **русский**, но с автоопределением по Telegram | сначала `language_code` пользователя; `en` → английский, `ru`/`uk`/`be`/`kk` → русский; нет данных или другой язык → **ru** (основная аудитория русскоязычная) |
| Юридические тексты | **не переводим юридически значимо** | один рабочий язык — русский; английская версия, если появится, — «для удобства», и это написано на экране. Юридическую силу имеет только русская редакция |
| Названия игр | **переводим — это интерфейс, а не бренд** | «Сейф» → **Safe**, «Ракета» → **Rocket**, «Дуэль» → **Duel**. В английском интерфейсе кириллицы нет ни в одном месте, включая названия игр |

**Почему автоопределение, а не жёсткий русский.** Англоязычный игрок, попавший в приложение по
реферальной ссылке, не должен видеть кириллицу и уходить. При этом русский — база: если Telegram
молчит или язык не наш, показываем русский, а не «удобный» английский.

**Чего нельзя делать с определением языка.** Менять язык нельзя молча посреди сессии; выбор
игрока (если он переключил вручную) **сильнее** автоопределения и сохраняется; смена языка не
меняет ни правил игры, ни баланса, ни хода дуэли.

## 2. Текущее состояние: честная цифра

На 2026-11-12 переводов в коде **нет**:

| Что | Значение |
|---|---|
| Файлы фронтенда с кириллицей | **65** из `frontend/src/**` |
| Строк с кириллицей в `.tsx` без комментариев | **~1012** (36 файлов) |
| Каталогов перевода (`locales/**`) | **нет** |
| Механизма перевода (i18n-библиотеки) | **нет** |
| Самый густой файл | `AdminPanel.tsx` (183), `Safe.tsx` (132), `SafeCrack.tsx` (131) |

Значит, «два языка» — это **отдельная миссия**, а не правка в конце. Оценивать её как «перевести
строки» нельзя: кроме текста есть числа, суммы, даты, склонения («1 монета / 2 монеты / 5 монет»),
названия кнопок фиксированной ширины и звуковые подписи.

## 3. Правило, которое вступает в силу сейчас

**Новый пользовательский текст не хардкодится в разметку.** Пока каталогов нет, действует
правило «строки отдельно от логики»: текст собирается в одном месте, а не рассыпан по JSX.
Когда миссия локализации начнёт работу, ей не придётся выковыривать фразу из середины
обработчика — она уже лежит рядом с ключом.

Что это значит практически для агента:

- новый экран: текст в отдельном объекте/модуле того же компонента, `t('safe.deposit')`, а не
  `>Пополнить сейф<` посреди JSX;
- **не** переводим существующие 1012 строк «по ходу» — это scope миссии локализации, а не
  побочная правка карточки про сейф;
- **в английском тексте нет кириллицы вообще** — ни в названиях игр, ни в цитатах, ни в кнопках.
  «Сейф» в английском UI — это `Safe`, а не `Сейф (Safe)`;
- диагностика (`ApiError`, сообщения сервера) — **код + параметры**, не готовая фраза; текст
  подставляет представление;
- плюрализация — не `s + 'ов'`, а форма с числом; для русского нужен выбор из трёх форм
  (1 монета / 2 монеты / 5 монет), для английского — из двух (1 coin / 2 coins);
- валюта и суммы — общий форматтер с локалью (`ru-RU`, `en-US`), а не `toFixed(2)` в разметке.

## 4. Как должна выглядеть миссия локализации (эскиз, не ТЗ)

1. **Каркас.** Каталоги `frontend/src/locales/ru.json` и `en.json`, тип ключей, провайдер, хук
   `useT`. Ключи — плоские и говорящие (`safe.deposit.title`), не «строка №17». Там же —
   **выбор языка**: автоопределение по `language_code` Telegram (правила выше), ручной
   переключатель, память выбора в профиле игрока (не в localStorage вкладки), ru — fallback.
2. **Пилот на одном экране.** Перевод одного экрана целиком (предложение: главная или сейф) и
   переключатель языка — чтобы Мастер увидел результат глазами, а не в отчёте.
3. **Массовый перенос** по зонам: экраны продукта, админка (её можно позже: админ русскоязычный),
   ошибки, письма/уведомления в Telegram.
4. **Гейт.** Сборка падает, если в `.tsx` появилась кириллица вне комментариев и вне каталога
   перевода; ключи `ru` и `en` совпадают по составу; плюрализация проверена на 1/2/5.
5. **Проверка глазами.** Скриншоты ключевых экранов на обоих языках; длинный английский текст не
   ломает кнопки.

Оценка объёма (грубая, для планирования): каркас — 1 карточка; пилот-экран — 1; массовый перенос —
3–4 карточки по зонам; гейт — 1; проверка — 1. Итого **7–8 карточек**, то есть миссия целиком,
а не «между делом».

## 5. Чего не делаем

- **Не** ставим i18n-библиотеку «на всякий случай» до миссии: лишняя зависимость в бандле,
  которую никто не использует.
- **Не** переводим комментарии в коде: комментарии — для агентов и остаются русскими
  (`docs/REGULATION.md` §10).
- **Не** делаем машинный перевод без вычитки: «Vault» и игровые термины — бренд, а не словарь.
- **Не** обещаем локали, которых Мастер не просил: сейчас ровно **ru + en**.
- **Не** оставляем кириллицу в английском интерфейсе: названия игр — часть интерфейса, а не
  логотип (D-116). Единственное исключение — сам знак **Vault** в шапке: латиница читается в
  обоих языках.
- **Не** выдаём английский перевод юридического текста за юридически значимый: значима русская
  редакция, это должно быть написано рядом с текстом.

## 6. Глоссарий: как называется каждая игра по-английски

Это не «перевод на глазок», а **словарь продукта**: один и тот же термин во всех экранах, в
кнопках и в уведомлениях. Меняется только решением Мастера — иначе сейф на одном экране станет
`Safe`, а на другом `Vault`.

| Русский | English | Почему так | Не использовать |
|---|---|---|---|
| **Сейф** | **Safe** | короткое, совпадает с моделью `safe.glb` и маршрутом `/safe` | `Vault` — это продукт и вклад, а не игра; `Locker`, `Chest` |
| **Ракета** | **Rocket** | буквально и совпадает с `rocket.glb`, `/rocket` | `Missile`, `Ship` |
| **Дуэль** | **Duel** | совпадает с `/duel`, `DuelScene` | `Battle`, `Match` |
| **Вклад VAULT** | **VAULT deposit** | вклад — отдельная механика, не игра и не сейф | `Deposit` без уточнения (спутается с пополнением) |
| **Взлом сейфа** | **Safe crack** | совпадает с `SafeCrack` | `Hack`, `Break-in` |
| **Ставка** | **Bet** | стандартный термин | `Stake` (это про доходность) |
| **Вызов** | **Challenge** | «вызвать на дуэль» | `Call`, `Invite` |
| **Реванш** | **Rematch** | короткое | `Revenge` |
| **Взрыв** | **Crash** | краш-игра; совпадает с механикой | `Explosion` |
| **Высота** (коэффициент) | **Multiplier** | то, что видит игрок | `Height`, `Coefficient` |
| **Страховка** | **Insurance** | механика частичного возврата | `Safety`, `Hedge` |
| **Вклад** (в сейф) | **Deposit** | общий термин для денег внутрь | `Contribution` |
| **Залог / доступно** | **Available** | то, чем можно играть сейчас | `Free`, `Unlocked` |
| **Игрок** | **Player** | | `User`, `Gambler` |
| **Банк** (общий призовой) | **Prize pool** | «банк» в английском = финансовая организация | `Bank` |
| **Приз** | **Prize** | | `Win` (это результат, не сумма) |
| **Вернуть** | **Withdraw** / **Cancel** | зависит от экрана: деньги наружу — `Withdraw`, отмена действия — `Cancel` | `Return`, `Back` |
| **Номиналы** | **Chip values** | суммы быстрых ставок | `Denominations` |
| **Отсчёт** | **Countdown** | | `Timer` |
| **Итог** | **Result** | | `Summary` |

**Правило имени.** Игра называется так, как называется **файл модели и маршрут**: `safe.glb` /
`/safe` → `Safe`; `rocket.glb` / `/rocket` → `Rocket`; `/duel` → `Duel`. Если термин в UI и в
коде расходятся — правится UI, а не маршрут: маршруты уже опубликованы и их знают ссылки.

**Где это проверяется автоматически.** В миссии локализации появляется гейт: в `en.json` нет
кириллицы (проверка по диапазону `А-Яа-яЁё`), и каждый ключ с названием игры берётся из
глоссария, а не из вольного перевода.
