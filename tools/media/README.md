# tools/media — вырезание фона (хромакей)

Перенесено из `Creative36711/synapse` → `tools/media/` (источник: narthex, c842670).
Без этого инструмента генератор изображений бесполезен для 3D-пайплайна: **ИИ-генераторы не
отдают настоящий альфа-канал** — «прозрачный фон» в промпте даёт псевдо-шахматку серыми квадратами.

## Установка (одна команда, ~4 с)

```sh
tools/media/setup.sh --check          # venv /tmp/vault-media + Pillow + самотест (13 проверок)
export PATH="/tmp/vault-media/bin:$PATH"
```

Только `pypi.org` / `files.pythonhosted.org`. Без apt, без root, без Docker.
Работает и без Pillow — тогда падает на ImageMagick (без `--heal`).

## Пайплайн для референсов и текстур

1. Генерировать объект на **сплошном ядовито-зелёном** `#00FF00`, без пола, теней и градиентов —
   в промпте писать буквально `flat solid chroma key green background, pure #00FF00`.
2. Вырезать: `cutout-chromakey in.png out.png --mode auto --crop`.
3. **Посмотреть результат глазами** — обязательно, инструмент не гарантирует чистых кромок.
4. Получившиеся PNG — референсы для моделирования, не готовые ассеты: `.glb` собирается в Blender
   по этим формам (`tools/modeling/`), а не «вставляется» картинкой.

## Почему строгий ключ

Инструмент не вырезает **бирюзу и циан** ни в одном режиме (`b >= g * 0.75` → не фон). Для Vault
это критично: акцентный цвет проекта — `#22D3EE`, и мягкий ключ съедал бы светящиеся кольца и
визоры насквозь. Отключение — только флагом `--allow-cyan`, если фон снят в бирюзе.

| Флаг | Зачем |
|---|---|
| `--mode auto` | строгий ключ с краёв + зачистка замкнутых зелёных полостей + despill (по умолчанию) |
| `--mode color` | глобальный ключ по всей картинке (логотипы без зелёных деталей) |
| `--mode flood` | только внешний контур от краёв кадра (внутренние полости остаются) |
| `--mode points --points "X,Y"` | точечная зачистка полостей по координатам |
| `--no-despill` | не трогать зелёный ореол на кромках |
| `--heal` | лечилка: возвращает непрозрачность пикселям внутри фигуры (внешний фон не трогает) |
| `--crop` / `--no-crop` | обрезка пустых краёв |
| `--max-size N` | даунскейл длинной стороны |

## Проверено в фазе 0

Десять референсов в `docs/art-direction/refs/` (исходники `refs/src/*.jpg` — JPEG 4:4:4 с
хромакеем, вырезанные `refs/cut/*.webp`, обзор `refs/contact-sheet.png`),
самотест 13/13 зелёный. Одна честная особенность: если композиция заполняет весь кадр
(«ракета в тоннеле», `08`), ключ вырезает и тоннель — объект становится частью силуэта.
Для сложных сцен лучше генерировать объект отдельно, а фон собирать в Blender/Three.
